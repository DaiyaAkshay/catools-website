The problem every CA firm knows

Clients send data from different Tally versions. Open it in an older release and Tally refuses it. Open it in a newer one and Tally silently upgrades it — and your client can no longer open the data you send back. TallyDrop takes the guesswork out: it checks the data first, then opens the one Tally that matches.

Frequently asked

Does TallyDrop change my client's data?

No. It only reads the start of the small company file to learn the release. It never opens the data in a newer release automatically, because that would upgrade it.

Is it really free?

Yes — TallyDrop is free during early access. No card, no account, no sign-up inside the app.

Which versions are supported?

Tally.ERP 9, TallyPrime 1.x to 7.x and TallyPrime Edit Log, installed side by side. The exact release is read from TallyPrime 3.0+ data; older .900 data is matched by format.

Does it touch my Tally settings or licence?

No. Each launch uses a one-time copy of that Tally's own settings with only the data folder changed. Your tally.ini, licence and gateway settings stay exactly as they are.

Windows says “Windows protected your PC”. Is it safe?

TallyDrop is new, so Windows SmartScreen doesn't recognise it yet. Click More info → Run anyway. Always download it from catool.co.in.

Can I put it on every PC in my firm?

Yes. Copy TallyDrop.exe to each PC and run TallyDrop.exe --create-shortcut, or click Create desktop shortcut in the app.
